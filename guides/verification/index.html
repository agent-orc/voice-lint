Earlier local checks — 12 September 2026#

  • Baseline checks — earlier library, backend, runner, task, project-check and UI-state counts; later changes are outside this baseline.
  • Managed startup — pairing and mapped text units at that capture, without a current-availability claim.
  • Language and navigation — English default, language switching and compact or focus navigation.
  • Source provenance — the observed source hash, Git state and historical task version.
  • Earlier Voice website — the earlier five-page website scope, before the expanded HTML guides.
  • Dossier handoff — the retained VL-W1 handoff observation.
  • Selection workflow visual record — metadata for a retained keep-as-written fixture capture, not a complete workflow run log.
  • Evidence integrity manifest — byte counts, SHA-256 hashes and available capture times for the curated historical files.

Hash agreement identifies a retained file; it does not establish test correctness or release readiness. The original evidence files remain unchanged. New checks produce a new dated record rather than replacing an earlier observation.
